# Frontend — Indian Ramsar Wetlands Monitoring Portal

Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui frontend.

See the [repository root README](../README.md) for full setup instructions,
environment variables, and the overall project structure.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run lint
npm run typecheck
npm run format
```
