# Ramsar Site photographs

Put each site's photographs in a folder named after its official Ramsar Site
number, e.g. `2407/` for Nangal Wildlife Sanctuary. Files are shown in name
order on the site profile page (`/wetlands/<number>`), so prefix with `01-`,
`02-`… to control order.

Supported: .jpg .jpeg .png .webp .avif

Optional `credits.json` in the same folder maps a file name to its credit:

```json
{ "01-lake.jpg": "Photo: A. Photographer" }
```
